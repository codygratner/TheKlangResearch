1.0 Dynamic Data Loading: The file:/// CORS Wall & The Universal Adapter Architecture

The Problem: Inlining roadmaps into every HTML artifact inflates file sizes from 35KB to 180KB+ and burns thousands of generation tokens. However, calling fetch('roadmap.json') inside a local file:/// page triggers an immediate, uncatchable Chromium security rejection (origin: 'null').

❌ Why Raw fetch('file://') Fails RFC 6454

Chromium assigns opaque origin null to local files. The Fetch API explicitly rejects non-HTTP protocols, causing silent blank screens in offline webviews without zero-flag workarounds.

✅ The Hybrid Universal Adapter SOTA Pattern

In Antigravity Extension mode: uses Node.js Sidecar SDK / HTTP IPC.
In Standalone file:// mode: dynamically injects data/roadmap.data.js via a synchronous script tag. 100% CORS-proof, zero build tools.

// Universal Dual-Mode Loader Pattern (core/data_loader.js) class NkaiDataLoader { static async load(key, scriptPath, apiPath = `/api/${key}`) { window.NKAI_DATA = window.NKAI_DATA || {}; if (window.NKAI_DATA[key]) return window.NKAI_DATA[key]; // Mode 1: Antigravity Extension / Node.js HTTP Server if (window.location.protocol === 'http:' || window.sidecar) { const res = await fetch(apiPath); return (window.NKAI_DATA[key] = await res.json()); } // Mode 2: Zero-Dependency Offline file:/// Mode return new Promise((resolve, reject) => { const script = document.createElement('script'); script.src = scriptPath; script.onload = () => resolve(window.NKAI_DATA[key]); script.onerror = () => reject(new Error(`Failed to load ${scriptPath}`)); document.head.appendChild(script); }); } }

4.0 Contrarian Audit: The 3 Fatal Traps & The Pragmatic 80/20 Standard 80/20 Reality Check
1. The CORS Trap

Pitfall: fetch('roadmap.json') triggers a silent blank screen on file:///.
80/20 Rule: Dual-emission generator writes both .json and synchronous .data.js. Zero network stack needed.

2. The Audio Hazard

Pitfall: Synthesized Web Audio clicks bursting through high-gain monitor speakers during DSP testing.
80/20 Rule: Default to 100% silence. Haptics strictly opt-in via a persistent mute toggle.

3. The 380px Panel Squish

Pitfall: Crowding the header with 10 buttons wraps into 4 ugly lines, stealing 25% of visible canvas.
80/20 Rule: Right-anchored slide-over drawers with icon+badge triggers that collapse cleanly on narrow panels.

🏆 The Pragmatic 80/20 Architectural Verdict

1. Roadmaps: Decouple into .agents/sidecar/data/roadmap.data.js. Render via right-anchored slide drawer.
2. Sessions: Scan .agents/sidecar/packages/*.json into sessions_manifest.data.js. Expose [ 1 PAUSED ] in header with 1-click workshop resumption.
3. Blue-Sky: Adopt the 2x2 Decision Matrix and Bi-Directional Action Prompters. Keep Web Audio haptics strictly opt-in and silent by default.
4. Indestructible Portability: Ensure every sidecar continues running 100% offline from disk with zero external servers.
