This repository serves as the shared, centralized research and architectural design hub across our software and hardware music technology ecosystem. Following the RFC patterns of Rust and Kubernetes, eternal DSP mathematics, cross-cutting microcontroller hardware teardowns, interactive HTML research boards, and subagent soul harvests live here to keep individual code repositories lean, fast, and token-efficient.

## ⚡ The Hybrid 80/20 Research Invariant

- **Active Implementation Specs (`docs/specs/*.md`)** remain physically co-located inside their respective code repositories (`TheKlangSuite`, `ToadTracker`, `nkai`) to protect atomic Git commits, PR review fidelity, and `git bisect` historical tracking.
- **Deep Exploratory Research, Interactive HTML Canvases, & Transcripts** live here in `TheKlangResearch` to eliminate repository bloat and prevent AI agent context window degradation.
- **The Static Vault Index:** Synchronized into `TheKlangVault/Research/Master_Research_Index.md` on every sync pass. Zero Obsidian Dataview plugin dependency; 100% portable plain Markdown.
