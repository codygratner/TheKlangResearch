TBD-16 Tri-Core Architecture

Web research confirmed the exact specifications for the dadamachines TBD-16 hardware.

The Hardware Specs

  • Audio DSP (ESP32-P4): Dedicated exclusively to real-time audio computation. This is where The Klang Suite (TKS) DSP engine will run.
  • UI & Sequencing (RP2350B): Handles the 16-button grid, the 4 endless push-encoders, the OLED display, and all MIDI event parsing.
  • Connectivity (ESP32-C6): Handles WiFi and Ableton Link synchronization.

TKS DSP Integration (Blue Sky)

Porting The Klang Suite to TBD-16

  • The Challenge: The ESP32-P4 is powerful (400MHz, SIMD), but standard C++ JUCE plugins will not cross-compile cleanly to bare-metal embedded ESP-IDF environments.
  • The Solution: We must aggressively decouple the TKS `processBlock` and `TbdAudio::FastMath` into a pure, headless `C++20` static library. No `juce::String`, no `juce::AudioBuffer`, just raw float arrays.
  • Polyphony: As previously established, strict "Mono-with-Tails" voice allocation is mandatory here to keep the ESP32-P4 from stalling during heavy modulation.

ToadTracker Synergy (Blue Sky)

How the TBD-16 interacts with ToadTracker workflows.

Headless Sequencing & Parameter Locks

  • The UX Paradigm: ToadTracker can sequence TKS parameters via MIDI CC. But on the hardware, the RP2350B intercepts encoder turns while a step is held.
  • Visual Feedback: When a user parameter-locks a TKS knob on the TBD-16 hardware, ToadTracker's UI on the desktop should instantly highlight that step value in the tracker grid (e.g., column `04 6A`).
  • The Groovebox Workflow: The TBD-16 can run 16 tracks. If we use TKS as the sound engine for Track 1, the RP2350B just sends rapid-fire struct updates via SPI to the ESP32-P4 to update the synth parameters per-step.

Wireless Patch Sync (ESP32-C6)

The Connected Synth

  • The Hardware: The dadamachines TBD-16 has a dedicated ESP32-C6 chip for WiFi and Bluetooth.
  • The Workflow: No USB cables required to load presets. When you hit "Save" on The Klang Suite desktop VST, the JSON parameter payload is silently broadcast over the local UDP network.
  • Instant Hardware Update: If the TBD-16 is on the same WiFi network, it catches the UDP packet, updates its PSRAM, and instantly plays the new sound. Designing sounds on the PC while playing them on the hardware becomes entirely seamless.
